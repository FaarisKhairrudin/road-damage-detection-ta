# Mendekatkan Table II ke penyebutan pertama

Pengguna menyetujui penyesuaian dengan "ya coba". Table II semula tertunda ke halaman 4 walau disebut di IV-B halaman 3. Percobaan placement bottom saja tidak mengatasi antrean float: Table I dua kolom baru masuk antrean pada halaman 3 dan memblokir Table II sampai halaman berikutnya.

Solusi akhir: memajukan deklarasi Table I sebelum subsection Metrics and Comparison Rules agar tabel dua kolom dapat muncul di bagian atas halaman 3. Table II tetap memakai placement fleksibel [!htbp]. Hasilnya Table II berada langsung setelah akhir paragraf pertama IV-B, di bagian atas kolom kanan halaman 3. Isi tabel dan angka tidak diubah.

Validasi: kompilasi berhasil; render halaman 3 diperiksa, tabel dan gambar tidak tumpang tindih. Table II kini satu halaman dengan penyebutan pertama dan langsung mengikuti paragraf pengantarnya.

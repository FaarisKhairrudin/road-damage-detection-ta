# Penghimpunan pedoman penulisan template TA

## Permintaan dan otorisasi

Pada 2 November 2026 pengguna meminta satu Markdown di folder template yang menyimpan seluruh aturan agar tidak hilang ketika isi LaTeX diganti. Permintaan eksplisit ini mengotorisasi pembuatan dokumen; tidak mengubah naskah LaTeX atau PDF.

## Sumber dan cakupan

- Sumber utama: `/home/varys/Downloads/TEMPLATE BUKU TA FIF.docx`, dibaca dari XML DOCX.
- Konteks tambahan: `AUDIT-PANDUAN.md`, `PANDUAN-PENGISIAN.md`, implementasi format, dan koreksi pengguna sebelumnya.
- Dokumen baru: `latex/buku-ta-template/PEDOMAN-PENULISAN.md`.

## Isi dokumen

1. Ringkasan lengkap aturan format, struktur, abstrak, bab, bahasa, tabel/gambar/persamaan, kutipan, pustaka, catatan kaki, serta lampiran.
2. Contoh penggunaan LaTeX dan petunjuk kompilasi sebagai panduan implementasi yang dibedakan dari aturan Word.
3. Perbedaan/typo sumber, termasuk ukuran A4, satuan berat kertas, caption, footer, rujukan tabel tanpa objek, serta panduan abstrak panjang.
4. Arsip 284 paragraf panduan dan contoh tidak kosong dari sumber; termasuk petunjuk per bab serta contoh kutipan/footnote/pustaka. Dua tabel data, persamaan contoh, dan tiga ilustrasi footnote juga disertakan.
5. Checklist sebelum penyerahan serta rekam SHA-256 DOCX sumber.

Identitas pribadi sampul/pengesahan dan cache daftar isi/nomor halaman tidak diarsipkan karena bukan aturan. Susunan/unsur halaman awal dan redaksi pokok pernyataan orisinalitas dihimpun dalam ringkasan. Aturan tertulis, temuan tampilan, dan keputusan implementasi ditandai agar tidak berubah menjadi peraturan resmi yang dikarang.

## Pemeriksaan

Memeriksa bahwa seluruh 284 paragraf terpilih ada dalam file Markdown, tabel data dan persamaan terwakili, fenced code berpasangan, daftar isi dan ilustrasi memiliki target yang tersedia, serta aturan penting tercakup. README dan INDEX diberi rujukan ke satu file pegangan utama. Tidak menjalankan kompilasi PDF karena perubahan hanya dokumentasi Markdown.
